# Simple CV

Vocabulary for the portfolio content and interaction model presented by this site.

## Language

**Portfolio Entry**:
An authored experience, project, or extra-curricular record presented in the CV.
_Avoid_: Item, card, content record

**Page Interaction Runtime**:
The browser-side coordination of arrival, reveal, scrolling, focus, and dialog behavior across the CV page.
_Avoid_: Layout script, animation utilities, DOM helpers

**Authored Content Verification**:
The shared rules that decide whether authored Portfolio Entries are structurally and semantically valid before publication.
_Avoid_: Content tests, frontmatter parser, schema checks

**Editorial Flow**:
The non-interactive visual layer that carries section indices and repeated shape fragments across adjacent page sections.
_Avoid_: Scroll effects, background decorations, parallax layer
