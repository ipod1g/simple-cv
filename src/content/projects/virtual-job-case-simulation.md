What does a job actually feel like? This project lets people try a job simulation, with an experience powered by ChatGPT prompts.

> **2,000+ users.** Launched for Accenture, L’Oréal, and PwC, with HKU and CUHK Career Center partnerships.

### Build the experience—and the team rhythm

I led **four frontend developers**, working across the interface and the workflow behind it. That meant reviewing pull requests, agreeing on code conventions, and keeping the team moving toward shared weekly goals.

### Put the work in front of people

Each week, I presented progress and demos to other project teams. Their feedback helped shape the next week’s priorities, keeping the build connected to the wider product.

### Built with

Next.js · React · TypeScript · Zustand · React Query · MongoDB · AWS
