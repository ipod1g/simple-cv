A slide editor built around a simple interaction: put something on the canvas, then move it until it feels right.

> **From personal experiment to product feature.** An extended version became part of Virtual Job Case Simulation.

### Start with the canvas

I built a WYSIWYG editor with draggable, resizable images and rich text. React handles the interface, with QuillJS providing the text editing tools.

### Give it a life beyond the demo

The company version added the pieces needed around the canvas: **PDF export, server-stored slides, and templates managed through an admin panel**. The personal build became a foundation for a larger product.

### Built with

React · QuillJS
