A web puzzle game with a Three.js frontend—and a challenge beyond the visuals: keeping the gameplay honest.

> **110,000+ visits.** More than 2,000 sign-ups for the web puzzle game.

### Design the invitation to play

I led the landing page and game UI/UX design in Figma, then developed the frontend with Vue and TypeScript. The work covered both the first impression and the experience inside the game.

### Think past the happy path

I focused on how the client and server communicated to help **prevent gameplay exploits**. Building the interface also meant thinking about what a player could manipulate.

### Keep the build coordinated

I collaborated with five developers through a GitOps workflow to develop and maintain the project.

### Built with

Three.js · Vue · Vuex · TypeScript · AWS · Figma
